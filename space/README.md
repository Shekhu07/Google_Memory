# Photo Retrieval Discovery Engine

A discovery engine over public Google Photos reviews and comments. It turns each post into a
structured record of one attempt to find a photo (clues kept, clues lost, where search broke,
workaround, outcome), audits those records with a second model family, and compares retrieval
problems using a decision rule written down before the data was seen.

Independent research prototype for a PM fellowship case study. Not affiliated with Google.

## Configuration
| Variable | Required | Default | Purpose |
|---|---|---|---|
| `GROQ_API_KEY` | yes (Space secret) | – | Live extraction in "Try a memory". Without it the tab falls back to text similarity. |
| `DEMO_MODEL` | no | `openai/gpt-oss-20b` | Model for live extraction |
| `DEMO_TOKEN_CAP` | no | `60000` | Daily token cap for the demo, so visitors can't use up the pipeline's quota |
| `DEMO_MAX_CHARS` | no | `500` | Max input length |

## Data
`data/` is generated by `engine/export_space.py` in the research repo. It contains structured fields,
short evidence quotes with links to the public source, and text embeddings, not full review text or author names.
